# PoS Toolbox — project page

Source of the project page for *When Does Unsupervised Learning Succeed or Fail? A PoS Perspective on
Reconstruction-Based Anomaly Detection* ([arXiv:2609.28832](https://arxiv.org/abs/2609.28832)).

Live at **https://artificialbrainstudio.github.io/PoS-AD/**. Every push to `main` redeploys it
through `.github/workflows/pages.yml`.

Preview locally: `python -m http.server` in this folder, then open http://localhost:8000/.
